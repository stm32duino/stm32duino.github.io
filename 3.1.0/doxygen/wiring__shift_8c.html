uint8_t shiftIn ( pin_size_t  dataPin,
pin_size_t  clockPin,
BitOrder  bitOrder 
)

Shift in a byte of data one bit at a time.

Each bit is read while the clock is HIGH, then the clock is set back to LOW.

Parameters
dataPinPin number to read the data from.
clockPinPin number to clock the data on.
bitOrderLSBFIRST or MSBFIRST.
Returns
The byte read.

Shift out a byte of data one bit at a time.

Each bit is written to the data pin, then the clock is pulsed HIGH then LOW.

Parameters
dataPinPin number to write the data to.
clockPinPin number to clock the data on.
bitOrderLSBFIRST or MSBFIRST.
valByte to shift out.
