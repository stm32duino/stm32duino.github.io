Output a debug message on stderr.

Does nothing when NDEBUG is defined.

Note
Using the printf function of the C library inflates the size of the code and uses a lot of stack. An alternative would be to implement a tiny and limited functionality implementation of printf.
Parameters
formatprintf-style format string, followed by the variables to print.
