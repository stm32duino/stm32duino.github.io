    Libraries

    This page lists libraries included with the STM32 core, STM32duino libraries, expansion-board libraries, and selected libraries from Arduino. Compatibility depends on the library, board, and STM32 device, so check each library's requirements and examples before use. Install libraries through the Arduino Library Manager when available; see each library's documentation for required dependencies and board-specific setup. See additional libraries and compatibility for Arduino libraries, community-tested libraries, and compatibility guidance.

    Warning

    Some Arduino shields route SPI through an ICSP connector, which may not be present on an STM32 board. Check the board pinout and connect MISO, MOSI, and SCK to the appropriate pins when needed.

    Note

    All STM32duino libraries are available through the "Library Manager" or have a look hereafter to see which one is available:

    • http://www.arduinolibraries.info/architectures/stm32

    Built-in (delivered with the core package)

    • CMSIS_DSP: see the CMSIS-DSP reference and the usage example here
    • EEPROM: follow the official EEPROM API, see also the EEPROM emulation reference
    • IWatchdog: see here
    • Servo: follow the official Servo API, see also the Servo reference
    • SoftwareSerial: follow the official SoftwareSerial API.
      It uses an hardware timer. Interrupt is triggered at a frequency = Baudrate * OVERSAMPLE (by default 3*baudrate) to handle RX as well as TX transmissions. This impacts CPU load specially at high baudrate.
    • SPI: follow the official SPI API, see also the STM32 SPI reference
    • Wire (I2C): follow the official Wire API, see also the STM32 I2C reference
