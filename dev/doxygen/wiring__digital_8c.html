void pinMode ( pin_size_t pinNumber,
PinMode pinMode )

Set the mode of a pin.

If the pin was used for PWM or DAC output (analogWrite()), the output is stopped first. Any unsupported mode calls Error_Handler().

Parameters

pinModeINPUT, INPUT_PULLUP, INPUT_PULLDOWN, INPUT_ANALOG, OUTPUT or OUTPUT_OPEN_DRAIN.
