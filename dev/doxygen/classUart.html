Detailed Description

STM32 hardware UART.

Implements the Arduino Stream and HardwareSerial API.

Use one of the constructors to bind a UART to pins or to a peripheral, then call begin().

◆ _rx_complete_irq()

void Uart::_rx_complete_irq ( serial_t *  obj)
static

RX interrupt handler.

Stores the received byte in the receive buffer.

Note
Called from the UART interrupt context: it must stay short and never block. If the receive buffer is full, the received byte is dropped.
Parameters
objUART object that received the byte.

◆ _tx_complete_irq()

int Uart::_tx_complete_irq ( serial_t *  obj)
static

TX interrupt handler.

Starts the next chunk of queued data, if any.

Note
Called from the UART interrupt context when a transfer completes: it must stay short and never block. A chunk never wraps around the end of the transmit buffer, so a wrapped buffer is sent in two transfers.
Parameters
objUART object whose transfer completed.
Returns
-1 if a new transfer was started, 0 if the transmit buffer is empty.
