◆ CDC_TransmitQueue_ReadBlock()

uint8_t * CDC_TransmitQueue_ReadBlock ( CDC_TransmitQueue_TypeDef *  queue,
uint16_t *  size 
)

Get a contiguous block of queued data to transmit.

Note
The block is the biggest flat (non wrapping) block available, so it may be shorter than the total queued data when it wraps around the end of the buffer. It is meant to be sent in USB packets of at most CDC_QUEUE_MAX_PACKET_SIZE bytes. The block is reserved until CDC_TransmitQueue_CommitRead() is called.
Parameters
queuetransmit queue.
sizeoutput: length of the returned block in bytes.
Returns
pointer to the first byte of the block.
