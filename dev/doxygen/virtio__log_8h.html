Write data to the OpenAMP trace buffer.

Note
By writing OpenAMP trace (log) buffer here, the Linux host can access to the content by the following command: $ cat /sys/kernel/debug/remoteproc/remoteproc0/trace0
When the buffer overflows (2kb by default, configurable.), the buffer is cleaned by a null character. Consider increasing VIRTIO_LOG_BUFFER_SIZE if a larger log buffer is needed.

dataData to send.
