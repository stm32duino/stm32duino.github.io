◆ main()

int main ( void  )

Main entry point of the Arduino application.

Calls initVariant() and setup() once, then runs loop() and serialEventRun() forever. When CORE_CALLBACK is defined, CoreCallback() is called before each loop().

Returns
0. Never reached in practice, the main loop never ends.

◆ premain()

void premain ( )

Early initialization, run before static object allocation.

Sets the NVIC priority grouping, enables the caches if present, then calls init().

Note
Forced to be called first (constructor priority 101), i.e. before static object allocation. Otherwise, statically allocated objects that need the HAL may fail.
