Detailed Description

Interrupt driven part of the U(S)ART driver, used by HardwareSerial: reception and transmission, HAL callbacks and IRQ handlers.

Kept apart from uart.c, so a sketch which only uses the debug UART (core logs, printf()) does not link the strong USARTx_IRQHandler() and can define its own. This file is a member of core.a, it is extracted when HardwareSerial references one of its functions.
