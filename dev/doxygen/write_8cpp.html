Write to a file descriptor, called by the C library.

The output of stdout and stderr (printf(), core_debug()...) is sent to the debug UART by uart_debug_write(), which initializes it when it is not already used by a Serial instance.

Note
The UART driver is linked as soon as this function is requested by the C library: using printf() or enabling the core logs (NDEBUG not defined) links it, with its strong USARTx_IRQHandler().
Weak, a sketch can provide its own.
Parameters
fileSTDOUT_FILENO and STDERR_FILENO for the debug output, STDIN_FILENO is ignored, otherwise a pointer to a Print object (Print::printf()).
