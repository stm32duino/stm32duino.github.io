Gives the number of seconds and microseconds since the Epoch.

Based on milliseconds since last power on.

Note
The function is declared as weak to be overwritten in case of other implementations in user file (using RTC values for example).
Parameters
tvArgument is a struct timeval.
tzArgument is a struct timezone (unused).
Returns
0, always.
