unsigned long pulseIn ( pin_size_t  pin,
uint8_t  state,
unsigned long  timeout 
)

Measures the length (in microseconds) of a pulse on the pin.

Works on pulses from 2-3 microseconds to 3 minutes in length, but must be called at least a few dozen microseconds before the start of the pulse.

Note
This function relies on micros() so cannot be used in noInterrupt() context.
Parameters
pinPin number, Dx or x.
stateHIGH or LOW, the type of pulse to measure.
timeoutMaximum time to wait for the whole measure (end of any previous pulse, start and end of the pulse), in microseconds. Defaults to 1 second when omitted in C++.
Returns
Length of the pulse in microseconds, or 0 if the pulse was not completed before the timeout.
