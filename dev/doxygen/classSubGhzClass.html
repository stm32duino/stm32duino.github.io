◆ attachInterrupt()

void SubGhzClass::attachInterrupt ( callback_function_t  callback)

Attach the handler called from ISR context when the radio IRQ triggers, then clear any pending IRQs and enable the IRQ.

The radio IRQ is level triggered, so the callback must either process the IRQ and clear the IRQ flags in the radio (so the radio clears its DIO lines before the ISR returns), or disable the IRQ to prevent it from being triggered over and over again.

Parameters
callbackFunction called from ISR context when the radio IRQ triggers.

◆ enableInterrupt()

void SubGhzClass::enableInterrupt ( )

Enable the interrupt again if it was previously disabled using disableInterrupt().

This does not clear pending interrupts: if the IRQ triggered while it was disabled, the callback registered with attachInterrupt() fires directly.

bool SubGhzClass::isBusy ( )

Get the busy signal exported by the radio module.

Uses the RFBUSYS flag, which returns the radio busy signal directly, not the RFBUSYMS flag that also returns an extra busy period after every SPI transaction.

◆ setNssActive()

void SubGhzClass::setNssActive ( bool  value)

Update the NSS signal internally connected to the radio SPI block.

The NSS signal is active-low: passing true activates the block (NSS driven LOW), passing false deactivates it (NSS HIGH).

Parameters
valuetrue to activate the NSS signal, false to deactivate it.
