◆ stm32_interrupt_enable()

void stm32_interrupt_enable ( PinName  pn,
callback_function_t  callback,
uint32_t  mode 
)

Enable the EXTI interrupt on a pin and register its callback.

The pin is configured as an interrupt input, keeping its current pull configuration, and the EXTI IRQ is enabled with EXTI_IRQ_PRIO / EXTI_IRQ_SUBPRIO priorities.

Parameters
pnPin name (e.g. PA_0) to attach the interrupt to.
callbackFunction called when the interrupt fires.
modeTrigger mode, e.g. GPIO_MODE_IT_RISING, GPIO_MODE_IT_FALLING or GPIO_MODE_IT_RISING_FALLING (hal_exti_trigger_t when USE_HALV2_DRIVER).
