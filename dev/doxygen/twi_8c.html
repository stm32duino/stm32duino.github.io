◆ get_i2c_obj()

i2c_t * get_i2c_obj ( I2C_HandleTypeDef *  hi2c)

Get the i2c_t object that embeds a given HAL I2C handle.

Parameters
hi2cPointer to the handle member of an i2c_t object (I2C_HandleTypeDef, or hal_i2c_handle_t with USE_HALV2_DRIVER).
Returns
Pointer to the i2c_t object that contains hi2c.
Note
The object is recovered by pointer arithmetic (container_of style). hi2c must point to the handle member of a valid i2c_t, otherwise the result is undefined.

◆ HAL_I2C_ErrorCallback()

void HAL_I2C_ErrorCallback ( I2C_HandleTypeDef *  hi2c)

I2C error callback.

Note
In master mode, the callback is not used because the error is reported to the Arduino API from i2c_master_write() and i2c_master_read(). In slave mode, there is no mechanism in Arduino API to report an error so the error callback forces the slave to listen again.
Parameters
hi2cPointer to a I2C_HandleTypeDef structure that contains the configuration information for the specified I2C.
