◆ analogInputToDigitalPin

#define analogInputToDigitalPin (   p)    (NUM_DIGITAL_PINS)

Convert an analog pin number (Ax) to a digital pin number.

Used by the analogRead API to have A0 == 0, even if the analog pins are not contiguous in the digitalPin array.

Parameters
pAnalog pin number.
Returns
Digital pin number, with the ALTX bits preserved. NC if the pin is not valid, or NUM_DIGITAL_PINS when no analog input is defined.
