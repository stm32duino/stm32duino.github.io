#define PNUM_ANALOG_BASE   0xC0

Pin number Analog base.

To check if a pin number is an analog pin: ((p & PNUM_ANALOG_BASE) == PNUM_ANALOG_BASE) if true then p is an analog pin number else not

◆ PNUM_ANALOG_INDEX

#define PNUM_ANALOG_INDEX   0x3F

Pin number Analog index.

Allows to retrieve the pin number index of an analog pin in the analogInputPin[] array: analogInputPin[p & PNUM_ANALOG_INDEX]
