◆ FLASH_PAGE_SIZE

#define FLASH_PAGE_SIZE   ((uint32_t)(8*1024)) /* 8kB page */

Size of the flash area used for the EEPROM emulation.

FLASH_PAGE_SIZE is not defined for STM32F2xx, STM32F4xx and STM32F7xx Could be redefined in variant.h or using build_opt.h

Warning
This is not the sector size, only the size used for EEPROM emulation. Anyway, all the sector size will be erased. So pay attention to not use this sector for other stuff.

◆ eeprom_read_byte()

uint8_t eeprom_read_byte ( const uint32_t  pos)

Read a byte from the emulated EEPROM (flash).

With a real data EEPROM, pos is a relative address and 0 is returned if it is out of range. Otherwise the flash content is first copied into the EEPROM buffer.

Parameters
posAddress to read.
Returns
Data read from EEPROM.

◆ eeprom_write_byte()

void eeprom_write_byte ( uint32_t  pos,
uint8_t  value 
)

Write a byte to the emulated EEPROM (flash).

With a real data EEPROM, pos is a relative address and the write is ignored if it is out of range. Otherwise the byte is written to the EEPROM buffer, then the whole buffer is written into flash.

Parameters
posAddress to write.
valueValue to write.
