Detailed Description

SPI controller or peripheral instance.

The default instance is SPI.

Constructor & Destructor Documentation

SPIClass::SPIClass ( pin_size_t  mosi = MOSI,
pin_size_t  miso = MISO,
pin_size_t  sclk = SCK,
pin_size_t  ssel = PNUM_NOT_DEFINED 
)

Construct an SPI instance using the given pins.

Default values are the pins of the default SPI peripheral defined in the variant. All pins must be attached to the same SPI peripheral, see the datasheet of the microcontroller.

Parameters
mosiSPI MOSI pin. Accepted format: number, Arduino format (Dx) or ST format (Pxy).
misoSPI MISO pin. Accepted format: number, Arduino format (Dx) or ST format (Pxy).
sclkSPI clock pin. Accepted format: number, Arduino format (Dx) or ST format (Pxy).
sselOptional SPI SSEL pin, must be a hardware CS pin managed by the SPI peripheral itself (see PinMap_SPI_SSEL[] in the PeripheralPins.c file of the board and the datasheet of the microcontroller). If set, no other CS pin can be used and no CS pin must be passed to any function of the class. Default: not defined (no hardware SSEL).
Note
To create another SPI instance attached to another SPI peripheral, give its pins as parameters.

void *  rx_buf,
size_t  count

Transfer several bytes using one constant Tx buffer and one Rx buffer.

begin() or beginTransaction() must be called at least once before. Expands the SPI API, see https://github.com/arduino/ArduinoCore-API/discussions/189

Parameters
tx_bufArray of Tx bytes filled by the user before the transfer. If NULL, dummy 0xFF bytes are clocked out.
rx_bufArray of Rx bytes filled by the peripheral during the transfer. If NULL, the received data is discarded.
countNumber of bytes to send/receive.
