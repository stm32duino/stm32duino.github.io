Macro Definition Documentation

◆ RPMSG_BUFFER_SIZE

#define RPMSG_BUFFER_SIZE   (512)

Size of buffer of each vring buffers.

Note
If the host processor is Linux, RPMSG_BUFFER_SIZE must be aligned with the kernel definition. Reference: https://elixir.bootlin.com/linux/v5.5.2/source/drivers/rpmsg/virtio_rpmsg_bus.c#L137

◆ VRING_NUM_BUFFS

#define VRING_NUM_BUFFS   (16)

Number of rpmsg buffers.

This means that a single call of rproc_virtio_notified(rvdev.vdev, VRING1_ID) will trigger VirtIOSerial::rxCallback() VRING_NUM_BUFFS times at maximum. A buffer handles VirtIOSerial::rxCallback() requires to be (RPMSG_VRING_PAYLOAD_SIZE * VRING_NUM_BUFFS) at minimum to prevent overflow.
