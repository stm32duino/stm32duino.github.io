Macro Definition Documentation

◆ VIRTIO_BUFFER_SIZE

#define VIRTIO_BUFFER_SIZE   (RPMSG_VRING_TOTAL_PAYLOAD_SIZE * 1 + 1)

Size of virtio ring buffer.

Note
See virtio_config.h for the size decision. (7937 bytes by default) The multiplier should be at least 1. As a result, the minimum required size of the initial virtio_buffer_write_available() must be RPMSG_VRING_TOTAL_PAYLOAD_SIZE.
If VIRTIO_BUFFER_SIZE is still too big, RPMSG_VRING_TOTAL_PAYLOAD_SIZE can be reduced by reducing the number of VRING_NUM_BUFFS in virtio_config.h.
