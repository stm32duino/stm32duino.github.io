◆ endTransmission() [1/2]

uint8_t TwoWire::endTransmission ( bool  stopBit)
override

Send the buffered data to the slave device and end the transmission.

Originally endTransmission() had no parameter. The stopBit parameter indicates whether or not a STOP is performed on the bus: calling endTransmission(false) allows a sketch to perform a repeated start.

Warning
Nothing keeps track of whether the bus tenure has been ended with a STOP. It is very possible to leave the bus in a hung state if no call to endTransmission(true) is made. Some I2C devices behave oddly if they do not see a STOP.
Parameters
stopBittrue to send a STOP at the end of the transmission, false to keep the bus for a repeated start.
Returns
0: success, 1: data too long, 2: NACK on address, 3: NACK on data, 4: other error.

size_t  len,
uint32_t  iaddress,
uint8_t  isize,
bool  stopBit 
)

Request bytes from a slave device after writing an internal register address.

This allows a repeated start to access the internal registers of a device.

Parameters
address7-bit address of the slave device.
lenNumber of bytes to request.
iaddressInternal register address to write before the request.
isizeSize in bytes of the internal address (most significant byte first), limited to 3.
stopBittrue to send a STOP after the request, false to keep the bus for a repeated start.
Returns
Number of bytes read, 0 on error. Read them with available() and read().
