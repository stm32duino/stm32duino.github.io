bool uart_init ( serial_t *  obj,
uint32_t  baudrate,
uint32_t  databits,

uint32_t  stopbits,
bool  rx_invert,
bool  tx_invert,
bool  data_invert 
)

Initialize the UART interface.

The U(S)ART peripheral is deduced from the pins set in obj (pin_tx, pin_rx, pin_rts, pin_cts). Swapped TX/RX pins are supported when the series allows it. If pin_rx is NC, the UART is configured in half-duplex mode.

Parameters
objPointer to serial_t structure.
baudrateBaud rate.
databitsWord length.
parityParity configuration.
stopbitsNumber of stop bits.
rx_invertInvert the RX line.
tx_invertInvert the TX line.
data_invertInvert the data bits.
Returns
true on success, false otherwise (obj is NULL, pins do not match the same U(S)ART peripheral or HAL initialization failed).
