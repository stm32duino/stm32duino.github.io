◆ analogReadResolution()

void analogReadResolution ( int  res)
extern

Set the resolution of analogRead return values.

Default is 10 bits (range from 0 to 1023).

Note
The ADC is configured with the closest supported hardware resolution (capped to the maximum of the ADC) and the result is scaled to the requested resolution. Values outside the range 1 to 32 call Error_Handler().
See also
analogRead(), analogWriteResolution()
Parameters
resNumber of bits of the resolution, from 1 to 32.

void analogWriteResolution ( int  res)
extern

Set the resolution of analogWrite parameters.

Default is 8 bits (range from 0 to 255).

Note
The PWM hardware resolution is capped to 16 bits and the value is scaled accordingly. Values outside the range 1 to 32 call Error_Handler().
See also
analogWrite(), analogReadResolution(), analogWriteFrequency()
Parameters
resNumber of bits of the resolution, from 1 to 32.
