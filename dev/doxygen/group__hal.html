Configure a pin: mode, speed, output type, pull-up/pull-down and alternate function.

Parameters
pinPin name.
functionPin function, encoded with the STM_PIN_* macros.
Note
Error_Handler is called if the pin is NC or the mode is unknown.
On series with dualpad analog switch (Pxy_C pins), the analog switch is also configured, and the GPIO configuration is skipped when an analog function is requested on the dualpad pin.
