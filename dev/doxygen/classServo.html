Detailed Description

Servo motor controller.

Each instance drives one servo on a pin, using a shared 16 bit timer.

uint8_t Servo::attach ( pin_size_t  pin,
int  min,

int  value = DEFAULT_PULSE_WIDTH

Attach the servo to a pin, with custom min and max pulse widths.

The pin is set as output and the servo is moved to the initial value. The min and max values are used to limit the writes and have a resolution of 4 microseconds.

Parameters
pinPin number to attach the servo to.
minPulse width in microseconds for 0 degrees (MIN_PULSE_WIDTH by default with the 2 parameters version).
maxPulse width in microseconds for 180 degrees (MAX_PULSE_WIDTH by default with the 2 parameters version).
valueInitial value, as an angle in degrees or a pulse width in microseconds. Default: DEFAULT_PULSE_WIDTH.
Returns
Index of the channel used, or INVALID_SERVO if no channel is available.
